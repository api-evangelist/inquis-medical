# Inquis Medical

> Inquis Medical is a privately funded medical device company founded in 2020 and headquartered in
> Menlo Park, California, dedicated to advancing the treatment of venous thromboembolic disease (VTE).
> Its AVENTUS Precision Thrombectomy System is a single-catheter mechanical thrombectomy platform
> combining a directional intelligent tip, an integrated 5F navigation catheter and dilator, TrueClot
> real-time tissue sensing at the catheter tip, and in-line filtration with autologous blood
> reinfusion — with no capital equipment. Inquis Medical publishes no public developer program and no
> machine-readable API contract.

## API surface

Inquis Medical has no public API. As of 2026-08-23 there is no developer portal, no API reference, no
OpenAPI/Swagger/AsyncAPI/GraphQL/MCP contract, and no `api.`, `developer.`, `docs.`, `dev.`, `app.`,
`portal.` or `partners.` hostname resolving on the inquismedical.com domain (all NXDOMAIN). Contract
discovery was run against the one host the company operates: `/openapi.json`, `/openapi.yaml`,
`/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc` and `/graphql` all return the
WordPress theme 404 page; `/llms.txt` and `/.well-known/security.txt` return a real nginx 404; the
whole `/.well-known/` directory — including `agent-card.json` and `agent.json` — is answered by a 403
WAF interstitial, so there is no A2A agent card. No SOAP `?wsdl` surface exists. No first-party SDK or
client library is published on npm, PyPI, or any other registry.

The company's product is clinical hardware — a catheter system used at the point of care by
interventional physicians — so the absence of an API is a fact about what Inquis Medical sells, not a
gap in its engineering. The only machine-readable JSON served from inquismedical.com is the stock
WordPress core REST API at `/wp-json/` (namespace `wp/v2` and plugin namespaces), which is the
marketing site's CMS discovery document, not an Inquis Medical product API, and is deliberately not
catalogued as one.

Inquis Medical does operate a public GitHub organization, `InquisMedical`, created in October 2022. It
contains a single repository, `SPI_DMA` ("SPI with DMA", embedded firmware), which is empty — zero
bytes, no commits with content since May 2023.
